Privacy policy

Last updated: October 19, 2026

Who uses this app

clip-machine is a personal tool. Its only user is its owner, who signs in with their own Google account to upload videos to their own YouTube channel.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload videos and read basic statistics (such as view counts) for videos on the owner's channel. It requests nothing else.

Where data is kept

The sign-in token Google issues is stored only on the owner's own computer, in a file only the owner can read. No data is sent to any server run by this app, because there isn't one.

Sharing

No data is sold, shared, or used for advertising. Nothing from Google APIs is transferred to anyone.

Google API Services

clip-machine's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time from their Google Account permissions page, and can delete the local token file.
